# Portafolio · Aldo Angel Ambriz Contla

Portafolio personal de QA Engineer y Desarrollador. Sitio estático con diseño
glassmorphism (efecto glass con blur), tema claro/oscuro y una sección de
proyectos con panel lateral interactivo.

## Tecnologías

- HTML5
- CSS3 (glassmorphism, variables de tema, animaciones)
- JavaScript (vanilla)

## Estructura

```
mi-portafolio/
├── index.html      # Página principal
├── css/style.css   # Estilos (tema claro/oscuro, glass UI)
├── js/script.js    # Interacciones (tema, menú, proyectos)
└── img/            # Imágenes de apoyo
```
